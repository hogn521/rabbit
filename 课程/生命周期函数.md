## Vue3 生命周期函数（组合式API）

### 什么是生命周期

每个 Vue 组件从**创建 → 挂载 → 更新 → 卸载**，会经历一系列阶段。生命周期函数（钩子）就是在这些阶段的特定时刻被调用的函数，让你在这些时机执行自己的代码。

### 生命周期流程图

```
创建 setup()
 │
 ├─→ onBeforeMount()     ← DOM 挂载前
 │
 └─→ onMounted()         ← DOM 挂载完成，可以操作 DOM
       │
       ├─→ onBeforeUpdate() ← 数据变化，DOM 更新前
       │
       └─→ onUpdated()      ← DOM 更新完成
              │
              ├─→ onBeforeUnmount() ← 组件卸载前（清理定时器等）
              │
              └─→ onUnmounted()     ← 组件卸载完成
```

### 各阶段说明

#### 1. setup() — 入口

最先执行，此时组件实例刚创建，**没有 DOM**，不能访问 `this`。

```vue
<script setup>
console.log('1. setup 最先执行')
</script>
```

---

#### 2. onBeforeMount — 挂载前

DOM 还没渲染，通常不需要手动用。

```js
import { onBeforeMount } from 'vue'

onBeforeMount(() => {
  console.log('DOM 即将挂载')
})
```

---

#### 3. onMounted — 挂载完成（常用）

DOM 已经渲染完毕，可以操作 DOM、发请求、初始化第三方库。

```vue
<script setup>
import { ref, onMounted } from 'vue'

const box = ref(null)  // 用 ref 绑定 DOM

onMounted(() => {
  console.log('DOM 已挂载')
  console.log(box.value)      // ✅ 可以拿到 DOM 元素
  // 适合：发请求、初始化图表、获取焦点
})
</script>

<template>
  <div ref="box">内容</div>
</template>
```

---

#### 4. onBeforeUpdate — 更新前

响应式数据变化了，但 DOM **还没更新**。

```js
import { ref, onBeforeUpdate } from 'vue'

const count = ref(0)

onBeforeUpdate(() => {
  console.log('DOM 即将更新，count =', count.value)
})
```

---

#### 5. onUpdated — 更新完成

DOM 已经更新完毕，可以访问更新后的 DOM。

```js
import { ref, onUpdated } from 'vue'

const count = ref(0)

onUpdated(() => {
  console.log('DOM 已更新完成')
})
```

> 注意：不要在 `onUpdated` 里修改响应式数据，否则会导致无限循环更新。

---

#### 6. onBeforeUnmount — 卸载前（常用）

组件即将被销毁，**在这里做清理工作**：

```js
import { onBeforeUnmount } from 'vue'

let timer

onMounted(() => {
  timer = setInterval(() => console.log('tick'), 1000)
})

onBeforeUnmount(() => {
  clearInterval(timer)  // ✅ 清理定时器
})
```

---

#### 7. onUnmounted — 卸载完成

组件已经销毁，所有事件监听和子组件都已被移除。

```js
import { onUnmounted } from 'vue'

onUnmounted(() => {
  console.log('组件已卸载')
})
```

---

### 完整代码示例

```vue
<script setup>
import { ref, onMounted, onBeforeUpdate, onUpdated, onBeforeUnmount, onUnmounted } from 'vue'

const count = ref(0)
const box = ref(null)

onMounted(() => {
  console.log('3. DOM 已挂载', box.value)
  console.log('可以操作 DOM 了')
})

onBeforeUpdate(() => {
  console.log('4. 数据变了，DOM 即将更新')
})

onUpdated(() => {
  console.log('5. DOM 已更新')
})

onBeforeUnmount(() => {
  console.log('6. 组件即将卸载，清理资源')
})

onUnmounted(() => {
  console.log('7. 组件已卸载')
})

function add() {
  count.value++
}
</script>

<template>
  <div ref="box">
    <p>{{ count }}</p>
    <button @click="add">+1</button>
  </div>
</template>
```

---

### 常见应用场景

| 生命周期 | 做什么 |
|----------|--------|
| **onMounted** | 发请求获取数据、初始化图表、获取 DOM 元素、初始化地图 |
| **onBeforeUpdate** | 获取更新前的 DOM 状态（如滚动位置） |
| **onUpdated** | 数据更新后做后续操作（注意不要修改数据） |
| **onBeforeUnmount** | 清除定时器、取消订阅、移除事件监听、断开 WebSocket |
| **onUnmounted** | 组件卸载完成后的日志记录 |

---

### 选项式 API vs 组合式 API 对照

| 选项式 API | 组合式 API |
|------------|------------|
| `beforeCreate` | `setup()` 本身 |
| `created` | `setup()` 本身 |
| `beforeMount` | `onBeforeMount` |
| `mounted` | `onMounted` |
| `beforeUpdate` | `onBeforeUpdate` |
| `updated` | `onUpdated` |
| `beforeUnmount` | `onBeforeUnmount` |
| `unmounted` | `onUnmounted` |

> `setup()` 替代了 `beforeCreate` 和 `created`，不需要单独写这两个了。

---

### 注意事项

1. 生命周期函数**必须在 `setup()` 或 `<script setup>` 期间同步调用**，不能放在异步函数里
2. `onMounted` 是操作 DOM 的最早时机
3. 记得在 `onBeforeUnmount` 里清理定时器、订阅等资源，避免内存泄漏
